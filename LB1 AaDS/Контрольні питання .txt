1. Що таке IDE PyCharm?
PyCharm — це інтегроване середовище розробки (IDE) від компанії JetBrains, призначене для програмування на Python. Воно надає інструменти для написання, аналізу та налагодження коду, включаючи інтелектуальне автодоповнення, підсвічування синтаксису, графічний зневаджувач та підтримку веб-фреймворків.

2. Що таке система контролю версій (СКВ) і для чого вона призначена? У чому полягає принципова відмінність СКВ SVN і GIT?
Система контролю версій (СКВ) — це інструмент для відстеження змін у файлах проєкту з часом, що дозволяє легко повертатися до попередніх версій, співпрацювати в команді та керувати історією змін. Основна відмінність між SVN і Git полягає в їхній архітектурі: SVN є централізованою системою, де вся історія зберігається на одному сервері, тоді як Git є розподіленою системою, де кожен розробник має повну локальну копію репозиторію. 

3. Що відбувається унаслідок виконання команди git add .?
Команда додає усі зміни у робочому каталозі та його підкаталогах до індексу, готуючи їх до наступного коміту.

4. Що відбувається унаслідок виконання команди git commit?
git commit – використовується для фіксації змін у репозиторії. Коміт зберігає зміни у вашому сховищі та додає їх в історію проекту.

5. Якою Git-командою виконується розміщення локальної копії Git-репозиторію проекта на віддаленому, що знаходиться на GitHub?
Для зв’язування поточного репозиторію з віддаленим можна скористатися такою командою: git remote add <nickname> <url>.
